# Himeko PPMP

CICT-PPMP, rewritten in Typescript. Aims to be a study of secure and performant coding with new tools and frameworks.

## What is it

CICT-PPMP is a capstone project I was a part of and most importantly, a reallocation and tracking system for Bulacan State University's College of Information and Communications Technology that aims to streamline the tracking and reallocation process of the workers behind it under the current traditional process. It leverages ML to also provide a decision support for the reallocation system to optimize budget against procurement items using different metrics.

This is a rewrite of the system from the ground-up from database design to the user interface. This rewrite aims to provide a more performant and more maintainable version of the currently built system. Furthermore, this also serves as a study project with new tools and frameworks and the web itself. Lastly, this is purely out of self-imposed incompetence that I am trying to rebuild it from scratch to prove to myself I am more than what I think of myself.

## Tech Stack

- Bun
- Supabase
- ElysiaJS
- Drizzle
- React (leaning towards Svelte)

## Development

To start the development server run:

```bash
bun run dev
```

Open http://localhost:3000/ with your browser to see the result.
